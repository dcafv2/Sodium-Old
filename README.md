# Sodium 1.8.9

A backport of **Sodium** to Minecraft **1.8.9**, focused on improving rendering performance while keeping the classic 1.8.9 experience.

## Features

* ⚡ Improved rendering performance
* 🎮 Designed for Minecraft 1.8.9
* 🧩 Client-side optimization
* 📉 Reduced rendering overhead
* 🔧 Built with modern optimization techniques

## Installation

1. Download the latest `.jar` from the **Releases** page.
2. Install **Minecraft Forge 1.8.9**.
3. Put the Sodium `.jar` into your `mods` folder.
4. Launch Minecraft 1.8.9.

## Compatibility

**Minecraft:** 1.8.9
**Loader:** Forge 1.8.9

This is a work-in-progress port and some Sodium features may behave differently from the modern version.

## Status

🚧 **In Development**

The port is still being worked on. Expect bugs, missing features, and compatibility issues.
